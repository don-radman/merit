# Merit / Peak Signal / v1.0

Working identity based on approved direction 06, with a newly refined compact mountain M.

## Start here
- Merit-Brandbook-v1.pdf: 20-page searchable visual guide.
- Merit-Brandbook-v1.md: corresponding text for writers and AI tools.
- merit-brand-spec.json: machine-readable decisions.
- merit-tokens.css: implementation tokens; not a complete UI theme.

## Logo files
- assets/merit-mark-{graphite,bone,citron}.svg: primary transparent vector mark.
- assets/merit-micro-{graphite,bone,citron}.svg: no-snowcap mark for 16-31 px.
- assets/merit-lockup-{graphite,bone,citron}.svg: outlined Manrope wordmark with mark.
- Matching PNGs: transparent previews. SVG is authoritative.
- assets/merit-steel-hero.png: AI-generated expressive render based on master mark. Not master geometry.

## Fonts
Manrope 700/800 display, Inter 400/500/600 UI, IBM Plex Mono 400 references.
Font sources: Google Fonts repository, ofl/manrope, ofl/inter, ofl/ibmplexmono.
Licence texts are included. Self-host; use font-display: swap. Amounts use tabular figures.

## Implementation
All new mark shapes are reviewable v1 artwork. Keep clear space H/4, full mark >=32 px, micro 16-31 px. Do not stretch. Verify real UI contrast, localization and accessibility. The guide does not change the repository or assert production readiness. Public-view dots demonstrate a boundary; they are not an access-control mechanism.

## Provenance
Brief: updated user ZIP, docs/BRAND.md, DESIGN.md, README.md and existing UI files. Direction 06 selected by Dan Rodman, then refined toward premium gray steel and compact connected mountain M. Cover generated with the built-in image tool using the master silhouette as reference. PDF, typography and UI examples are programmatically typeset.
